# JANARIK — Haunted Music

Тёмный адаптивный музыкальный веб-интерфейс, вдохновлённый красно-чёрной эстетикой *King of the Graveyard* и механикой стриминговых сервисов.

## Возможности

- интро «Жанар великий лорд made it»;
- каталог Sematary и Yung Lean, разбитый по релизам;
- поиск по трекам, артистам и альбомам;
- фильтры артистов, любимые треки и медиатека (localStorage);
- очередь, shuffle, repeat, next/previous, прогресс и громкость;
- встроенный 30-секундный генеративный demo-player на Web Audio API;
- адаптивная desktop/mobile вёрстка и управление с клавиатуры.

## Запуск

Откройте `index.html` или запустите локальный сервер: `python3 -m http.server 8080`

> Проект не содержит защищённых авторским правом аудиофайлов. Плеер генерирует короткий оригинальный demo-loop в браузере. Для коммерческого каталога подключите лицензированный streaming API.
